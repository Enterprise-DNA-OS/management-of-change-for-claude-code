Read CLAUDE.md. Find overdue change actions and pre-start-up actions still open after start-up.

Run `npm run moc -- overdue`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

"open after start-up" is the serious one: the plant is running on a change whose training or procedure is not done.
